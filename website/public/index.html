mode — session

为长会话而生的工作区

冷静、密集、可操作——每一个能力都围绕「动手之前可审批、做完之后可验证」。

会自我验证

改完自己跑测试复核，结果回到会话里；每一处改动都以 diff 呈现，不静默改文件。

动手前先许可

每一次编辑、命令与工具调用都可要求审批——仅本次允许、本项目内一直允许，或完全放行。

一个 Agent，三种界面

Tauri 桌面端、浏览器工作区与终端 TUI 共用同一个运行时和同一批会话。

IM 机器人

在微信 / 企业微信 / 飞书 / 钉钉里驱动工作区：私聊按人、群聊按群各自绑定独立会话。

局域网远程

UDP 广播发现同一网络里的另一台 Mode，一次性 6 位配对码授权后像本地一样使用。

远程被控端

Windows 机器运行单文件 mode-agent，经 MCP Streamable HTTP 接受指令：命令、文件、进程、截屏与键鼠。

插件、技能与 MCP

内置插件市场，公开目录随包离线分发；MCP 服务按用户或工作区配置。

自带模型

内置 DeepSeek、OpenAI、Anthropic、Kimi、GLM、xAI 等预设，也支持完全自定义端点。

桌面、浏览器与终端，同一批会话

同一 workspace 的状态、审批与运行结果在三端之间保持一致；远程工作区支持 SSH、WSL 与 Docker。

macOS

Linux

Mode-<版本>-linux-x86_64.AppImage

chmod +x 后直接运行
